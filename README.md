# Word LaTeX converter for Mac

Mac版Microsoft Wordの本文に書いたLaTeXを、編集できるWord数式に一括変換するVBAマクロです。
実機テストでは3個の行列を含む式の変換に失敗しました。前後に置いたギリシャ文字の式と分数はどうなったでしょうか。

前後の2式はWord数式になり、行列の式は区切り記号ごとLaTeXのまま残りました。
マクロは作業用文書で式を一つずつ変換し、成功した式だけを本文に反映します。そのため、途中で変換できない式があっても他の式を処理できます。

## 変換する範囲

認識する区切りは `\(...\)`、`\[...\]`、`$...$`、`$$...$$` の4種類です。
変換したい箇所を選択すると、その範囲だけを処理します。本文内にカーソルを置き、何も選択しなければ本文全体を処理します。

既存のWord数式と、エスケープしたドル記号 `\$` はそのまま残します。
ヘッダー、フッター、脚注、テキストボックスは対象外です。

## 導入

配布ファイルはコード画面に貼り付ける `.txt` と、VBAエディターからインポートする `.bas` の2種類です。
**`.bas` の内容をコード画面へ直接貼り付けると、先頭の `Attribute VB_Name = ...` で構文エラーになります。**
4つのマクロは同じモジュールにあるため、この1行でどのマクロも実行できなくなります。

同名の旧マクロを使っている場合は、バックアップを取ってから置き換えてください。
参照設定の追加、外部ライブラリ、WindowsのCOMや正規表現エンジンは不要です。

### コードを貼り付ける

1. [WordLaTexConverter-paste.txt](WordLaTexConverter-paste.txt) を開き、ファイルの本文だけをコピーします。
2. Wordの「ツール」→「マクロ」→「Visual Basic Editor」を開きます。
3. 検証用の `.docm` 文書を選び、標準モジュールを追加して貼り付けます。
4. 「デバッグ」→「プロジェクトのコンパイル」を実行します。
5. `SelfTestLaTexConverter` を実行し、`Passed=24 Failed=0` を確認します。

### ファイルをインポートする

1. [WordLaTexConverter.bas](WordLaTexConverter.bas) をダウンロードします。
2. VBAエディターの「ファイル」→「ファイルのインポート」から読み込みます。
3. 「デバッグ」→「プロジェクトのコンパイル」を実行します。続けて `SelfTestLaTexConverter` を実行し、`Passed=24 Failed=0` を確認します。

## 一括変換の使い方

1. 元の文書を別名で保存します。
2. Wordの数式入力形式をLaTeXに設定します。
3. 本文内にカーソルを置くか、変換したい範囲を選択します。
4. `ConvertLaTexInDocument` を実行します。
5. 分数、添字、総和、行列の表示を確認します。`Retained` が1以上なら、変換できずに残ったLaTeXも確認します。

| マクロ | 用途 |
| --- | --- |
| `ConvertLaTexInDocument` | 本文のLaTeXを一括変換する |
| `CreateLaTexSmokeTest` | 4種類の区切りを含む基本テスト文書を作る |
| `SelfTestLaTexConverter` | 検出、原文保持、復元、既存数式の保護など24項目を確認する |
| `DiagnoseLaTexMatrices` | 7種類の行列入力を比較し、結果をWord文書に出力する |

## 実機で確認した動作

macOS 27.0.1とWord 16.114（ビルド16.114.1020）で、コンパイルと実行を確認しました。

| テスト | 結果 |
| --- | --- |
| 自己テスト | 24件成功、0件失敗 |
| 4種類の区切りを含む基本入力 | 4式を変換 |
| 同じ文書で再実行 | 重複変換なし |
| 3行列の式と前後の通常式 | 行列のLaTeXを保持し、前後の2式を変換 |

このビルドでは、`bmatrix` を2個または3個含む代表式で `BuildUp` が失敗しました。
複数の行列を含む式の変換は未解決です。

`\[...\]` と `$$...$$` も認識しますが、独立した表示数式の段落は自動で作りません。
変換時の検査だけでは数式の意味やすべての書式を確かめきれないため、文書のコピーで実行し、変換後の表示を確認してください。
