# Word LaTeX converter for Mac

Mac版Microsoft Wordの本文にあるLaTeXを、編集できるWord数式へ一括変換するVBAマクロです。
`\(...\)`、`\[...\]`、`$...$`、`$$...$$` を認識します。
選択範囲があればその範囲だけを、選択範囲がなければ本文全体を処理します。

変換を式ごとに作業用文書で試し、失敗した式は区切り記号を含む元のLaTeXを残します。
失敗後も他の式を処理します。
既存のWord数式と、エスケープされたドル記号 `\$` は変換対象から保護します。

## 検証状況と制限

macOS 27.0.1、Word 16.114、ビルド16.114.1020でコンパイルと実行を確認しました。

| 項目 | 実機結果 |
| --- | --- |
| 自己テスト | 24件成功、0件失敗 |
| 4種類の区切りを含む基本入力 | 4式成功 |
| 同じ文書で再実行 | 重複変換なし |
| 3行列を含む失敗式と前後の通常式 | 行列の原文を保持し、前後の2式を変換 |

複数の `bmatrix` を1式に含む問題は未解決です。
検証したビルドでは、2個から3個の行列を含む代表式が `BuildUp` で失敗しました。
表示用の区切りも認識しますが、独立した表示数式の段落は自動で作りません。
ヘッダー、フッター、脚注、テキストボックスは対象外です。

文書のコピーで実行し、分数、添字、総和、行列を確認してください。
検査を通過しても、数式の数学的意味やすべての書式の維持を保証するものではありません。

## 導入する

### コード画面へ貼り付ける場合

1. [WordLaTexConverter-paste.txt](WordLaTexConverter-paste.txt) を開き、ファイル本文だけをコピーします。
2. Wordの **ツール → マクロ → Visual Basic Editor** を開きます。
3. 検証用の `.docm` 文書を選び、標準モジュールを追加して貼り付けます。
4. **デバッグ → プロジェクトのコンパイル** を実行します。
5. `SelfTestLaTexConverter` を実行し、`Passed=24 Failed=0` を確認します。

### ファイルをインポートする場合

1. [WordLaTexConverter.bas](WordLaTexConverter.bas) をダウンロードします。
2. VBAエディターの **ファイル → ファイルのインポート** から読み込みます。
3. コンパイルと自己テストを実行します。

**`.bas` の内容をコード画面へそのまま貼り付けないでください。**
先頭の `Attribute VB_Name = ...` はインポート用の情報で、コード画面にあると構文エラーになります。
4つのマクロが同じモジュールを共有するため、この1行でどのマクロも実行できなくなります。
貼り付けには属性行のない `.txt` を使ってください。

同じ名前の旧マクロは、バックアップしてから置き換えてください。
参照設定の追加、外部ライブラリ、WindowsのCOMや正規表現エンジンは不要です。

## 使う

1. 元の文書を別名で保存します。
2. Wordの数式入力形式をLaTeXに設定します。
3. 本文内にカーソルを置くか、変換したい範囲を選択します。
4. `ConvertLaTexInDocument` を実行します。
5. 数式の表示を確認します。`Retained` が1以上なら、未変換のLaTeXも確認します。

| 公開マクロ | 用途 |
| --- | --- |
| `ConvertLaTexInDocument` | 本文の一括変換 |
| `CreateLaTexSmokeTest` | 4形式を含む基本テスト文書の生成 |
| `SelfTestLaTexConverter` | 検出、原文保持、復元、既存数式の保護など24項目の自己テスト |
| `DiagnoseLaTexMatrices` | 7種類の行列入力を比較し、結果文書を生成 |
